# 🚀 COMECE AQUI - Task Queue

## ⚡ Forma Mais Rápida (Recomendado)

### Para Windows:

1. **Dê duplo clique** em um destes arquivos:
   - `INICIAR.bat` ← **COMECE AQUI!**
   - `TaskQueueLauncher_v2.bat`

2. **Pronto!** A dashboard abre automaticamente

### Para Mac/Linux:

```bash
python3 iniciar.py
```

---

## 📋 Pré-requisito

Você precisa ter **Python 3.8+** instalado.

### Como instalar Python:

1. Acesse: https://www.python.org/downloads/
2. Baixe a versão mais recente
3. **IMPORTANTE:** Durante a instalação, marque **"Add Python to PATH"**
4. Clique em "Install Now"
5. Reinicie o computador

### Verificar se Python está instalado:

Abra CMD/PowerShell e digite:
```bash
python --version
```

Se aparecer a versão, Python está instalado! ✓

## 📊 Usando a Dashboard

Depois que abrir, você verá botões para:

- 📧 **Enviar Email** - Simula envio de email
- 📄 **Gerar Relatório** - Simula criação de PDF
- 🖼️ **Processar Imagem** - Simula processamento
- 🔄 **Sincronizar Dados** - Simula sincronização
- 🧹 **Limpar Cache** - Simula limpeza
- ⚡ **Executar Todas** - Cria todas as tarefas

## 🎓 O que é Task Queue?

Um sistema que:
- ✅ Recebe tarefas
- ✅ Coloca na fila
- ✅ Executa uma por uma
- ✅ Mostra status em tempo real

Muito usado em aplicações web! 🚀
